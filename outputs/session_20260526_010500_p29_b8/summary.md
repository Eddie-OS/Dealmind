2. 2. 如果不知道精确数字，应诚实告知并承诺立即查询，而不是反复重复模糊话术。
3. 3. 对比竞品时，必须给出具体差价，如“华为套装比三星便宜$100”。
4. 4. 销售过程中要倾听客户反馈，一旦客户指出问题，立即纠正，不可重复错误。
