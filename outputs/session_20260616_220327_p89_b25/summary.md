### 销售经验（可写入培训手册）
1. 1. When a customer asks for specific technical specs, never stall or promise future testing. If you don't know, immediately use a web search or consult a colleague. In a store, you can also grab a demo unit and test together on the spot.
2. 2. For in-store sales, always leverage the physical environment: invite the customer to test the device themselves, show sample files, and compare side-by-side with competitors. Never send the customer to check online later.
3. 3. If a web search tool fails, do not repeat the same failed action. Switch to another source (e.g., printed spec sheet, call a product specialist) or offer a live demo to answer the question empirically.
4. 4. Use reflection paraphrase early to confirm the customer's dealbreakers, then immediately address them with concrete evidence. Avoid repeating the same promise multiple times.
5. 5. For high-skepticism customers, build trust by admitting what you don't know and then taking immediate, visible action to find the answer (e.g., 'Let's look it up together on the official site right now').

### 可复用策略模式
- **Live Demo Verification Tactic**
  - 使用条件：When a customer asks for a spec you don't know, and you have a demo unit available.
  - 示例：Instead of promising a video later, say: 'Let's test it right now on this unit. I'll open GoPaint and we can export a file to see how layers are handled.'
- **Immediate Web Search Together Tactic**
  - 使用条件：When a customer asks for a spec and you have internet access in-store.
  - 示例：Say: 'Let's look it up together on the official site. I'll open consumer.huawei.com/jp right now.' This builds trust and shows transparency.
- **Dealbreaker Confirmation Loop Tactic**
  - 使用条件：When a customer repeatedly asks for the same information.
  - 示例：Paraphrase their concern: 'So the two specs that are dealbreakers for you are X and Y, correct?' Then immediately take action to address both, one at a time.
