### 销售经验（可写入培训手册）
1. When a customer asks for a live demo, provide it immediately or offer a video link; never ignore the request.
2. Use precise technical specifications (e.g., key travel, latency) to build credibility, but pair them with visual evidence.
3. Avoid mixing languages or irrelevant data; stay focused on the customer's current concern.
4. If unable to demo live, pivot to a detailed step-by-step description with analogies (e.g., 'feels like a wired keyboard').
