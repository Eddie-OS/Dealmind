### 销售经验（可写入培训手册）
1. 1. For skeptical customers, always lead with certifications and technical details before marketing claims. Use specific standards (e.g., TÜV 3.0) to build credibility.
2. 2. When a customer asks to see a feature in action, immediately perform a live demo. Never try to close before demonstrating all requested features.
3. 3. Use the in-store environment to your advantage: invite customers to touch, try, and trigger features themselves. This builds trust faster than verbal explanations.
4. 4. Avoid overusing the same playbook action (e.g., soft_hook). Vary techniques to keep the conversation engaging and address different customer needs.
5. 5. Confirm the customer's complete package (product + accessories + warranty) only after all concerns are addressed. Premature confirmation can derail the sale.

### 可复用策略模式
- **Certification Anchoring**
  - 使用条件：When customer expresses skepticism about product claims (e.g., eye strain reduction).
  - 示例：Lead with a specific certification (e.g., TÜV Rheinland Full Care Display 3.0) and explain what it tests. Then demonstrate how the product meets those standards.
- **Live Trigger Demo**
  - 使用条件：When customer asks to see a feature in action, especially automatic features.
  - 示例：Set up the feature (e.g., posture alert) and have the customer perform the action that triggers it (e.g., lean closer). Let them see it work without manual setup.
- **Package Confirmation After Demo**
  - 使用条件：When customer has seen all key features and is ready to buy.
  - 示例：Summarize the complete package (product + accessories + warranty) with exact prices only after all concerns are addressed. Then ask for the sale.
