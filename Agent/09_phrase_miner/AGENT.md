# 09 · 优秀话术提炼 Agent

全量对抗跑完后运行一次，从 N 场对话里捞出真正管用的话术。

## 判断"优秀"的依据

不靠模型自评"这句说得好"（那只会挑出最漂亮的空话）。
用**客户的行为反应**作为主信号：

一条销冠发言进入候选，要同时满足：

| 条件 | 理由 |
|------|------|
| 说完之后客户的 `purchase_signal` 上升 | 唯一的客观效果证据 |
| 本轮没被 `08_content_guard` 改写 | 编数字换来的信号提升不能要 |
| 自报引用了产品手册 | 一线复述得出来的话术才有复用价值 |
| 长度 ≥ 30 字 | 过滤"好的"、"没问题"这类无信息回应 |
| 所在会话质量分 ≥ `reports.min_turn_score` | 整场都很差时单轮的信号提升多半是噪声 |

排序按**信号提升幅度**降序，不是按分数。

另一路素材是 `07_coach_agent` 的 `suggested_rebuttals`（更优话术模板）。
它是模型建议的、**未经对话验证**的版本，在报告里单独成节并明确标注，
不和"实战验证过"的话术混在一起。

## 归类方式

用异议主题聚类，把每条话术挂到它回应的那类异议下（价格 / 竞品 / 信任 /
需求不明 / 决策权 等）。分类依据是**该话术前一句客户原话**，不是话术本身。

## 输入

`runs/<run_id>/sessions/*/session_log.json`

## 输出

| 文件 | 内容 |
|------|------|
| `runs/<run_id>/reports/excellent_phrases.md` | 按异议主题分组的话术库，每条带客户原话、信号提升、出处 |
| `runs/<run_id>/reports/excellent_phrases.jsonl` | 同样内容的机器可读版，一行一条 |
| `runs/<run_id>/steps/09_phrase_miner/*.md` | 筛选过程：每道筛子刷掉了多少条 |

## 成本

**零额外模型调用**。全部基于已落盘的数据推导。

## 单独运行

```bash
python 09_phrase_miner/run.py                  # 处理最近一次 run
python 09_phrase_miner/run.py --run-id run_xxx
```
